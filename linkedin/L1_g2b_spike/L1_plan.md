# L1 — 나라장터 API 스파이크 · 세부계획

> 2026-09-16 작성 · 상태 **승인 대기** · 승인 전 실행하지 않습니다

---

## 1. 이 단계의 성격

**스파이크입니다.** 산출물은 코드가 아니라 **판정**입니다.

작성하는 조회 스크립트는 탐색용이며, 판정이 통과할 경우에만 L2에서 정식 수집기로 승격합니다. 통과하지 못하면 폐기합니다. 스파이크 단계에서 수집기를 제대로 만들려 하지 않습니다.

---

## 2. 답할 질문 — 단 하나

> **조달청 OpenAPI에 온프렘 스토리지 단가가 TCO 계산에 쓸 수 있는 형태로 존재하는가.**

트랙 B 전체가 여기 걸려 있습니다. L3(온프렘 CapEx 모델)부터 착수하면 데이터가 없을 때 전부 폐기하게 되므로, 판정을 먼저 내립니다.

---

## 3. 판정 기준

| # | 확인 항목 | 통과 조건 |
|---|---|---|
| ① | 품목 분류 | 스토리지 장비가 조회 가능한 분류로 잡히는가 |
| ② | 용량 필드 | TB/GB 용량이 **구조화 필드**로 있는가 (규격 문자열 파싱만 가능하면 부분 통과) |
| ③ | 벤더 식별 | 제조사명이 식별 가능한가 (Dell / HPE / NetApp 등) |
| ④ | 단가 성격 | 총액인가 단위당인가. **총액뿐이면 용량으로 나눠야 하므로 ②에 의존** |

**중단 조건:** ①~③ 중 **둘 이상 불가** → 트랙 B 폐기, 해외 리스트가(트랙 C)로 후퇴하고 L2 계획을 다시 씁니다.

**부분 통과 시:** 규격 문자열 파싱이 필요하면 파싱 신뢰도를 표본 30건으로 측정하고, 그 수치를 L2 진입 여부 판단에 씁니다.

---

## 4. 실행 순서 — 2단계로 나눕니다

인증키 발급이 사용자 조치 대기이므로, **키 없이 가능한 부분을 먼저** 합니다.

### L1-a · 명세서 기반 스키마 확인 (인증키 불필요 — 즉시 가능)

공공데이터포털 각 API의 활용가이드·응답 명세에 **응답 필드 목록이 공개**되어 있습니다. 실제 조회 없이 ②③④를 상당 부분 판정할 수 있습니다.

대상 4종:

| API | 링크 | 확인할 것 |
|---|---|---|
| 종합쇼핑몰 품목정보 | [15129471](https://www.data.go.kr/data/15129471/openapi.do) | 품목 규격·단가 필드 |
| 나라장터 계약정보 | [15129427](https://www.data.go.kr/data/15129427/openapi.do) | 물품 계약 단가·수량 |
| 나라장터 낙찰정보 | [15129397](https://www.data.go.kr/data/15129397/openapi.do) | 낙찰 단가 |
| 나라장터 가격정보현황 | [15129415](https://www.data.go.kr/data/15129415/openapi.do) | 조사가격 성격 |

**여기서 이미 "용량·제조사 필드가 어디에도 없다"가 나오면 키를 받기 전에 중단합니다.**

산출물 — `L1_schema_survey.md` (API별 응답 필드 표 + 1차 판정)

### L1-b · 실조회 검증 (인증키 필요)

L1-a가 통과한 API에 한해 실제 조회합니다.

1. 품명 키워드 검색 — `스토리지`, `디스크어레이`, `저장장치`, `스토리지서버` 등으로 물품분류번호를 **역추출**합니다. 분류번호를 먼저 추측하지 않습니다.
2. 역추출한 분류번호로 최근 2~3년 계약 건 조회
3. 표본 30건을 뽑아 ①~④ 판정
4. Dell / HPE / NetApp 제조사별 건수 확인 — 건수가 한 자릿수면 통계적으로 못 씁니다

산출물 — 조회 스크립트(탐색용) + 샘플 응답 JSON + `L1_result.md`

## 5. 기술 사항

- 위치: `linkedin/L1_g2b_spike/` **안에서만** 작업합니다. `src/`·`data/`는 이 단계에서 건드리지 않습니다.
- 인증키는 **파일에 쓰지 않고** 환경변수(`G2B_SERVICE_KEY`)로 읽습니다. 샘플 응답을 저장할 때 키가 URL에 포함되지 않도록 마스킹합니다.
- 조회는 표본 확보 목적이므로 페이지 수를 제한합니다. 전량 수집하지 않습니다.
- 응답 원본을 그대로 남깁니다 — 판정 근거가 되어야 하므로 가공본만 남기지 않습니다.

## 6. 선행 조건 — 사용자 조치

**공공데이터포털 인증키 발급이 필요합니다.**

1. [data.go.kr](https://www.data.go.kr) 회원가입·로그인
2. 위 4개 API에서 **활용신청** (자동승인이면 즉시, 심의 대상이면 1~2일)
3. 마이페이지 → 오픈API → **일반 인증키(Encoding/Decoding)** 확보

키를 주시면 환경변수로 받아 진행하겠습니다. **키 없이도 L1-a는 지금 시작할 수 있습니다.**

## 8. 이 단계에서 하지 않는 것

- 수집기 정식 구현 (L2)
- `data/pricing.yaml` 수정 (L2)
- CapEx 변환 모델 (L3)
- 전량 수집 — 표본만 봅니다
- 스토리지 외 품목(서버·네트워크) 조사 — 범위 확장 금지
